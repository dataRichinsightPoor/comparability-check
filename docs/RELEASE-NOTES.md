# Comparability Check v0.5.0

Data-Rich, Insight-Poor CCLX · 99 Small Problems · No. 07

This MIT-licensed research-use release adds a guided cell-context lesson, reproducible simulation stress tests, and a source-linked comparison guide. All bundled examples and parameter distributions are synthetic.

## Included

- Eight-step Raji-versus-engineered-cell walkthrough, with matched axes, optional interpretation reveals, explicit sandbox transfer and downloadable handout.
- Six seeded repeated endpoint experiments plus a paired-cell sensitivity ensemble, with browser cancellation and JSON/Markdown exports.
- 100,000 iterations per scenario in each of four committed configurations: 2.4 million repeated endpoint experiments in total.
- Bias, conditional 95% coverage, equivalence-declaration rates, nonsignificance rates, and Monte Carlo uncertainty.
- An exact counterexample showing identical EC50 values but response-dependent dose ratios when slopes differ.
- Literature-backed guidance and the preceding [Data-Rich, Insight-Poor CCI essay](https://www.linkedin.com/pulse/assay-got-better-because-cells-worse-ermelinda-damko-6kvme).

## Boundaries

The model does not validate biological comparability, fit raw dose-response curves, diagnose genomic integration, or predict rituximab effector function. The generic reporter is explicitly separate from CD20 biology. MIT licensing permits reuse; it does not imply fitness for a regulated assay decision.
